- Added `onCreateDelimitedOptions` to `EuiComboBox`, called once with all new values when `delimiter` is set and multiple values are created at once (e.g. pasting a delimited or newline-separated list). Prefer this over `onCreateOption` if your consuming code derives its next state from a captured/controlled value, since calling `onCreateOption` once per value in a loop can drop all but the last value.

**Bug fixes**

- Fixed `EuiComboBox` so that pasting a newline-separated list (e.g. copied from rendered pills/badges elsewhere in the UI) is split into multiple values when `delimiter` is set, instead of collapsing into a single value
