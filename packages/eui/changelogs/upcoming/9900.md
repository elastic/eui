- Decreased `EuiTitle` letter-spacing via `font.title.letterSpacing` (`-0.2px`)
- Changed default `EuiText` color to subdued (`textSubdued`); pass `color="default"` for full paragraph contrast. `EuiTextColor`'s `default` is unchanged
- Changed default `EuiText` `size` to `s` (~14px) to match theme body / unstyled `html`; pass `size="m"` for the previous ~16px default

**Breaking changes**

- Default `EuiText` is quieter and smaller when `color` / `size` are omitted. Opt into `color="default"` and/or `size="m"` where the previous appearance is required
