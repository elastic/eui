**Bug fixes**

- Fixed virtualized `EuiCodeBlock` remounting all rows on every re-render, which caused flickering and lost text selection when content updates
- Fixed virtualized `EuiCodeBlock` losing its scrollable height when a `style` prop is passed

**Breaking changes**

- Virtualized `EuiCodeBlock` now ignores `height`, `minHeight`, `maxHeight`, `blockSize`, `minBlockSize`, `maxBlockSize` and `all` passed in `style`, as `react-window` controls the list's block size
