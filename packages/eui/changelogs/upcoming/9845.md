- Updated `EuiButtonGroup`:
  - Added new render API via `children` prop that allows passing button components as children
  - Added `variant` prop (usable only with `children` prop)
  - Added `gutterSize` prop (usable only with `children` and `variant="default"` prop)
- Updated `EuiButton`, `EuiButtonEmpty` and `EuiButtonIcon` to consume a `EuiButtonContext` allowing the group to control common props

**Bug fixes**

- Fixed a visual bug in `EuiButtonGroup` that rendered duplicate borders on disabled buttons
