- `EuiComboBoxObject.setSelectedOptions()` now types to filter before selecting (matching by accessible name, with a keyboard fallback for duplicates), so it works on filterable / virtualized / suggestion-backed combo boxes
- `EuiComboBoxObject.setSelectedOptions()` accepts a `timeout` option (default `2500`ms) to bound how long each option is awaited after typing, for slow / server-backed combo boxes
- Added `EuiComboBoxObject.setCustomSelectedOptions()` to set free-text values via `onCreateOption`, and `getAvailableOptions()` to read the available (unselected) option labels
- `EuiComboBoxObject` now verifies the `data-test-subj` element is actually an `EuiComboBox` and throws a clear error otherwise, instead of silently operating on the wrong component

**Bug fixes**

- `EuiComboBoxObject.getSelectedOptions()` now reads selected pills by the `.euiComboBoxPill` class instead of its `data-test-subj`, so combo boxes that stamp a per-option `data-test-subj` (which overrides the pill's own) are read correctly
