# Loading

Use loading indicators sparingly and opt for showing actual [progress](./progress.mdx#progress-with-values) over infinite spinners. It is ok to use multiple loaders on a page if each section is progressively loaded. However, if the entire page is loaded at once, use a single, larger loading indicator.

## Elastic ring

**EuiLoadingElasticRing** is the branded ring indicator for product and full-page loading. Prefer it for Elastic-branded loading screens. Set `loading={false}` to settle into the static design before unmounting.

```tsx interactive
import React from 'react';
import { EuiLoadingElasticRing } from '@elastic/eui';

export default () => <EuiLoadingElasticRing />;
```

## Elastic

The **EuiLoadingElastic** loader is great for full page or Elastic product loading screens.

```tsx interactive
import React from 'react';
import { EuiLoadingElastic } from '@elastic/eui';

export default () => (
  <div>
    <EuiLoadingElastic />
    &emsp;
    <EuiLoadingElastic size="l" />
    &emsp;
    <EuiLoadingElastic size="xl" />
    &emsp;
    <EuiLoadingElastic size="xxl" />
  </div>
);
```

## Logos

**EuiLoadingLogo** accepts any of our [EuiIcon](./icons/index.mdx#elastic-logos) logos. It should only be used in very large panels, like fullscreen pages.

```tsx interactive
import React from 'react';
import { EuiLoadingLogo } from '@elastic/eui';

export default () => (
  <div>
    <EuiLoadingLogo />
    &emsp;
    <EuiLoadingLogo logo="logoObservability" size="l" />
    &emsp;
    <EuiLoadingLogo logo="logoSecurity" size="xl" />
  </div>
);
```

## Chart

To indicate that a visualization is loading, use **EuiLoadingChart**.

```tsx interactive
import React from 'react';
import { EuiLoadingChart } from '@elastic/eui';

export default () => (
  <div>
    <EuiLoadingChart size="m" />
    &nbsp;&nbsp;
    <EuiLoadingChart size="l" />
    &nbsp;&nbsp;
    <EuiLoadingChart size="xl" />
  </div>
);
```

## Spinner

**EuiLoadingSpinner** is a simple spinner for most loading contexts. It is drawn in `currentColor`, so it inherits the text color of its parent.

```tsx interactive
import React from 'react';
import { EuiLoadingSpinner } from '@elastic/eui';

export default () => (
  <div>
    <EuiLoadingSpinner size="s" />
    &nbsp;&nbsp;
    <EuiLoadingSpinner size="m" />
    &nbsp;&nbsp;
    <EuiLoadingSpinner size="l" />
    &nbsp;&nbsp;
    <EuiLoadingSpinner size="xl" />
    &nbsp;&nbsp;
    <EuiLoadingSpinner size="xxl" />
  </div>
);
```

## Agentic

**EuiAgentLoader** is a quiet pulse for agent work that is happening now or in the background. The centre four dots move first, then the ring around them. Sizes are 12px, 16px, and 24px.

```tsx interactive
import React from 'react';
import { EuiAgentLoader } from '@elastic/eui';

export default () => (
  <div>
    <EuiAgentLoader size="s" />
    &nbsp;&nbsp;
    <EuiAgentLoader size="m" />
    &nbsp;&nbsp;
    <EuiAgentLoader size="l" />
  </div>
);
```

## Shimmering text

**EuiShimmeringText** is a status line for work in progress. The text stays subdued, and a highlight sweeps across it. Pass `texts` to swap through a sequence: the current line leaves upward as the next one rises in. The box stays as wide as the longest line.

```tsx interactive
import React from 'react';
import { EuiShimmeringText } from '@elastic/eui';

export default () => (
  <EuiShimmeringText
    texts={[
      'Planning next moves',
      'Reading the files',
      'Running a command',
      'Writing the changes',
    ]}
  />
);
```
