- Updated `EuiButtonGroup`:
  - Added new render API via `children` prop that allows to pass children as button components
  - Added `variant` prop (useable only with `children` prop)
  - Added `gutterSize` prop (useable only with `children` and `variant="default"` prop)
- Updated `EuiButton`, `EuiButtonEmpty` and `EuiButtonIcon` to consume a `EuiButtonGroupContext` allowing the group to control common props

**Bug fixes**

- Fixed a visual bug in `EuiButtonGroup` that rendered duplicate borders on disabled buttons
