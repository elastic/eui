- Changed **EuiPanel** defaults to flat bordered: `hasShadow={false}`, `hasBorder={true}`
- Wired `borderRadius="m"` to `border.radius.panel`
- Soft-deprecated Panel `paddingSize` `xs` / `xl` in favor of `none` / `s` / `m` / `l` (still accepted)
- Preserved elevated **EuiCard** / **EuiPopover** chrome by explicitly opting out of the new Panel border default where they need shadow/custom elevation
- **EuiEmptyPrompt:** `color="plain"` defaults to `hasBorder` so main + footer read as one container; `transparent` stays flush unless opted in

**Breaking changes**

- Bare `EuiPanel` is bordered and unshadowed; pass `hasBorder={false}` and `hasShadow` for the previous elevated look
- Plain `EuiEmptyPrompt` is bordered by default; pass `hasBorder={false}` to opt out
