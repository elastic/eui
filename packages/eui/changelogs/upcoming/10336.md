- Added `append` and `prepend` support to multi-select `EuiComboBox`. They were previously ignored unless `singleSelection` was set, so remove them from multi-select combo boxes that should not show them.
- Added a `selectionDisplay` prop to `EuiComboBox`, which defaults to `wrap`. The `collapse` value keeps selected options on a single line, truncates the last visible option to use the remaining space, and shows overflow in a popover, whereas `wrap` lets the control grow to show every selection.
- Updated `EuiFormControlLayout` side dividers to stretch across the full height of multi-row controls.
- Aligned `EuiComboBox` prepend and append content with the first row of a multi-row control.

**Bug fixes**

- Fixed the `EuiComboBoxProps` type, which typed `prepend` and `append` as `undefined`.
